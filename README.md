# Local Data Lake with Docker 🐳

Hands-on workshop materials for building and exploring a local Data Lake architecture using Docker and Docker Compose.

---

## 🏗️ Architecture & Services

This setup spins up a containerized local data sandbox, including:

- **Storage / Object Store:** (e.g., MinIO / S3-compatible storage)
- **Query Engine / Processing:** (e.g., Trino / Spark / Python environment)
- **Containerization:** Docker Compose for single-command orchestration

---

## 🚀 Prerequisites

Make sure you have installed:
- [Docker](https://docs.docker.com/get-docker/) (v20.10+)
- [Docker Compose](https://docs.docker.com/compose/)
